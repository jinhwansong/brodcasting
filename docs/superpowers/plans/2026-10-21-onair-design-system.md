# 디자인 시스템 실행 순서

구현·로컬 검증 완료: [검증 기록](../../verification/design-system.md). 알림5주에는 공통 UI를 적용했으며 해당 과정은 별도 미게시 제작 상태로 유지한다. 브랜치 CI 확인 후 검증한 커밋을 main에 반영한다.

기준은 [설계](../specs/2026-10-21-onair-design-system.md)다. 새 UI 제작보다 공통 기준 적용을 먼저 하라는 사용자 지시에 따른다.

1. 기존 스타일/계정/채팅/공지/RTC와 공개 검사 호출부를 확인한다. 알림5주 미게시 코드는 보존한다.
2. 공통 요소의 접근성·로딩·이름·입력 오류 검사와 전시 화면 동작 검사를 먼저 작성하고 실패를 확인한다.
3. ui의 의미 색·글자·간격·조작 크기와 React 요소를 구현한다. 화면 CSS는 배치 역할로 정리하고 반복 색을 토큰으로 바꾼다.
4. 목록의 방송 카드, 팔로우, 계정, 채팅, 공지, WebRTC의 실제 조작에 공통 요소를 적용한다. `#/design-system`에서 예제 동작과 상태를 확인할 수 있게 한다.
5. WebRTC 교재의 제공 UI와 알림5주 UI를 맞춘다. 학습 TODO·백엔드·사용자 미추적 문서는 건드리지 않는다.
6. 단위/행동/타입/빌드·독립 복사본을 검증한다. 실제 브라우저의 넓은/좁은 화면·키보드·오류/로딩/계정을 관찰한다. 원시 증거와 유지보수 안내를 기록한다.
7. 검증된 디자인 시스템 단위를 커밋·브랜치 게시·CI 확인 후 main에 반영한다. 이후 알림5주 교재 정리,6~7주·F1~F3·최종 통합을 이어간다.
