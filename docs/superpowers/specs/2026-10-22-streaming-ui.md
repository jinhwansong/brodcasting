# 방송 목록과 시청 UI

사용자는 생성 시안의 방향을 승인했고, 목록 제목 옆 프로필만 조금 줄여 달라고 요청했다. 기존 어두운 색과 민트색을 유지한다.

- 목록: 큰 홍보 영역 없이 썸네일·제목·진행자·시청자 수를 반복 배치한다. 샘플 데이터는 실제 LIVE처럼 표시하지 않는다.
- 제목20px 이상, 본문PC16px·모바일14px, 배지PC12~14px·모바일12px.
- 목록 프로필PC32px·모바일28px, 제목과 간격8px. 시청 화면의 프로필까지 작게 만들지 않는다.
- 기본 시청: 영상 왼쪽, 채팅 오른쪽, 방송 정보 아래. 휴대폰에서는 세로로 이어진다.
- 스크린 모드: 탐색 메뉴와 바깥 여백을 없앤다. 영상과 채팅 컴포넌트를 유지하고 CSS 배치만 바꾼다. 기본 모드 버튼과 Escape로 복귀한다. 영상 자체의 전체 화면 기능과 다르다.
- 포커스: 키보드 위치는 보여 주되 테두리를 이중으로 겹쳐 보이게 하지 않는다.
- 실제 서버의 제목·검색·팔로우·권한·채팅·공지·RTC 기능은 유지한다. 시안의 가상 방송자와 숫자를 실제 데이터로 넣지 않는다.

시안은 `apps/broadcast/client/public/design/streaming-preview.png`이며 내장 imagegen 도구로 생성했다. 디자인 가이드에 예시라고 명시한다. 핵심 프롬프트는 ‘Korean streaming UI, charcoal/mint, four-column media directory, basic watch with right chat and below-video channel details, theater mode without navigation’이다. 실제 구현에서 목록 프로필은 시안보다 작다.

학습 상태는0·미시작이다. 이 작업은 교재 R5~R7·F1~F3의 완료를 의미하지 않는다.

## 방송자 화면 추가 지시

사용자는 시청자 화면과 별도로 직접 방송할 때의 작업 환경도 UI와 기능을 연결해 달라고 요청했다. 기존 WebRTC 송출 기능을 ‘방송 스튜디오’에 모으고 ‘방송하기’와 ‘방송 찾기’를 구분한다. 방송 제목, 선택한 화면의 송출 미리보기, 테스트·카메라·화면 공유 시작, 마이크 선택, 종료, 방 주소와 실제 통계를 제공한다. 화면·카메라는 버튼을 누른 뒤 브라우저 권한 선택을 거친다. 기존 최대4명·로컬망 실습 범위는 유지한다. 이번 변경으로 녹화·OBS 연동·외부망 TURN·방별 라이브 채팅이 추가된 것은 아니다.
