# 온에어 라운지 화면 방향 변경

사용자가 기존 실습 화면의 시각 품질을 지적하고 SOOP·치지직 같은 방송 서비스 스타일을 요청했다. 기존 통합 계획의 흰색 중심 계약은 이 요청으로 바꾼다. 커리큘럼·학습 상태는 유지하며 통합 사이트의 화면 구현을 먼저 진행한다. 알림4주 제작물은 보존하고 이후5~7주·F1~F3·알림함 연결을 이어간다.

- 바탕 #0E1015, 탐색 #151821, 패널 #1E222D, 본문 #F3F5F8, 보조 #A4ADBE, 강조 #78E1CD. 방송 썸네일의 보라·청록·코랄 그림이 화면의 중심이다.
- 운영체제 한글 sans. 상단 로고/탐색/검색/계정, 왼쪽 추천·팔로잉·진행자 탐색, 가운데16:9 썸네일과 진행자·제목·주제의 위계. 시청 화면은 큰 영상+오른쪽 채팅, 아래 공지. 좁은 화면은 상단 탐색·1열 썸네일·영상 아래 채팅.
- SOOP·치지직의 탐색 구조를 참고하며 로고/상표/실제 방송 썸네일을 복제하지 않는다. 제공하는 여섯 방송은 학습용 샘플이며 시청자 수를 실제 접속자 수로 가장하지 않는다.
- 기본6의 세션·CSRF·즐겨찾기·DB 채팅 복구를 재사용한다. API 응답과 늦은 응답/계정 전환의 방어를 유지한다. 시청 선택은 hash 경로로 뒤로 가기를 지원한다. 샘플은 기존 r1/r2 연습방을 명시적으로 연결하며 이를 방송별 독립 채팅방이라고 주장하지 않는다.
- 입력/조회/저장/권한 거부/빈 결과/다시 시도 상태를 같은 디자인에 반영한다. 클릭해도 아무 일 없는 메뉴나 가짜 알림 건수를 만들지 않는다. 알림함은5주 연결 전까지 완료로 표시하지 않는다.

검토: 사용자가 방송 서비스의 어두운 스타일을 명시했으므로 해당 팔레트를 따른다. 모서리가 둥근 안내 박스의 반복 대신 미디어·제목·진행자 위계를 쓴다. 외부 폰트·아이콘 라이브러리·새 상태 관리 라이브러리는 추가하지 않는다. 실제 브라우저의 데스크톱/좁은 화면/키보드·재생·로그인·채팅을 관찰해 증거를 남긴다.
