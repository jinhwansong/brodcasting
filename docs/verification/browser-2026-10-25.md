## 음성 검증 중 확인한 점

- 사용자가 카메라 영상이 나온다고 확인했으며, 내 송출 미리보기에서 소리가 나지 않는다고 답했습니다. 소스의 로컬 미리보기 `muted=local`은 되울림 방지 목적입니다.
- 카메라는 `audio: microphone`으로 캡처하고 해당 체크는 기본 꺼짐입니다. 화면 공유는 `audio:false`입니다. 시청 스트림에서는 muted를 false로 설정합니다. 같은 계정의 시청을 이유로 소리를 끄는 분기는 없습니다.
- 사용자가 이후 시청 쪽 무음도 보고했습니다. 시청 화면은 음소거false·볼륨1·재생 중이지만, 이 도구의 read-only DOM 범위는 srcObject를 노출하지 않습니다. 따라서 초기 조회의 빈 배열을 실제 오디오 트랙0개라는 증거로 사용하지 않습니다. 마이크 전달·수신 음성은 **미확인**입니다.
- 실제 Chrome 창 접근은 도구에서 승인되지 않아 소리 설정을 읽거나 변경하지 않았습니다. OS/브라우저 마이크와 출력 장치, 사용자의 실제 청취 확인이 필요합니다.
- 안내 문구의 개발 화면 갱신 중 기존 방송이 종료됐을 가능성이 있어 새 공유 방을 받아 재접속했습니다. 이후 음성 진단 중 추가 화면 갱신은 중단했습니다.
