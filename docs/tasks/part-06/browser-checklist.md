- 빌드/서버 commit·DB 초기 조건:
- 사용한 테스트 계정과 방(비밀번호·cookie·token은 기록하지 않음):

| 확인 | 결과/증거 |
| --- | --- |
| 두 브라우저의 실제 cookie/Origin·회원권 분리 | 미실행 |
| 한쪽 단절 뒤 메시지 누적·재접속 이력 | 미실행 |
| commit 뒤 ack 유실·같은 ID 재시도1행 | 미실행 |
| 복구 중 live·중복 표시·500행 수동 재개 | 미실행 |
| 연결/발송 재시도 상한과 미확인 상태 | 미실행 |
| 계정/방 전환·세션 만료·logout·늦은 응답 | 미실행 |
| 키보드/라벨/포커스·메시지 읽기·좁은 화면 | 미실행 |
| 새로고침의 메모리 outbox/cursor 유실 경계 | 미실행 |

실제 관찰한 증상·Network/WS 프레임과 DB 결과를 분리합니다. 민감한 헤더를 공유하거나 테스트 통과만으로 학습 통과를 기록하지 않습니다.
