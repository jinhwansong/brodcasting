# 1단계 브라우저 후속 검증

**전체 미실행.** 사용자가 실제 브라우저 검증을 추후 진행하기로 했습니다. 제작 중 브라우저 설치를 재시도하지 않았습니다. jsdom의 역할·라벨·포커스·타이머 검증과 실제 화면 렌더링·보조기술 확인은 구분합니다.

학습자 시작 코드의 A~D를 완성한 뒤 `npm run dev:part-01`로 확인하세요. 제작자 참고 완성본을 확인할 때는 해당 폴더 README의 별도 명령을 사용합니다. 결과에 OS·브라우저 버전·뷰포트·커밋·날짜를 적으세요.

- [ ] 1280px: 목록과 상세 두 열, 긴 제목·검색어에도 가로 스크롤 없음
- [ ] 390px: 한 열로 전환, 버튼·입력·메뉴 패널·미디어 자리 표시자 넘침 없음
- [ ] 200% 확대: 내용 손실 없이 조작 가능, 텍스트가 겹치지 않음
- [ ] 키보드 Tab / Shift+Tab: 검색·정렬·목록 옵션·각 방송·즐겨찾기·실험 순서 확인, 포커스 표시가 보임
- [ ] 키보드로 상세 열기: 제목으로 이동, 상세 즐겨찾기 조작 시 포커스를 빼앗지 않음
- [ ] 상세 바로 닫기: 원래 방송 버튼으로 복귀
- [ ] 선택한 방송을 검색으로 숨긴 뒤 닫기: 검색 입력으로 복귀, 검색어 보존
- [ ] 메뉴: Enter/Space 열기·닫기, 체크박스와 초기화 버튼 Tab 접근
- [ ] 메뉴 내부 Escape: 닫힘과 트리거 복귀. 반복 실행 후 중복 반응 없음
- [ ] 메뉴 밖 입력·버튼 클릭: 닫히면서 클릭한 곳의 포커스 유지
- [ ] 상세 A → B → 닫기: 0부터 재시작, 닫은 후 증가·오류 없음
- [ ] 빈 데이터·오류·다시 시도: 안내와 복구가 보이고 조작 가능
- [ ] 스크린리더: 제목 계층·영역·검색/정렬 라벨·즐겨찾기 눌림·옵션 펼침 상태 전달 확인

체크는 실제 실행 후에만 표시합니다. 실패한 경우 재현 순서·기대/실제·화면 증거를 남깁니다.
