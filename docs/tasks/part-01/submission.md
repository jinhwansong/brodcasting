# 1단계 제출 기록

- 학습 상태: 미시작
- 작성자 / 날짜: 학습자 작성 대기
- 사용한 커밋: 작성 대기

## 실행 전 예상

1. 선택 방송을 검색으로 숨기고 닫았을 때: 작성 대기
2. 목록·상세의 즐겨찾기를 공유하는 방법: 작성 대기
3. 반복 열기·닫기·전환 시 이벤트와 타이머 수: 작성 대기

## 첫 시도와 실제 변경

- AI 도움 전 직접 시도한 부분: 작성 대기
- A / B / C / D에서 바꾼 파일과 이유: 작성 대기
- 제거한 중복 상태와 영향받는 화면: 작성 대기
- 틀린 예상과 확인한 원인: 작성 대기

## 실행 증거

| 확인 | 실행 명령·환경·날짜 | 실제 결과와 남은 실패 |
| --- | --- | --- |
| 타입 검사 | 미실행 | 작성 대기 |
| 빌드 | 미실행 | 작성 대기 |
| 공개 행동 검증 | 미실행 | 작성 대기 |
| 독립 변경 검증 | 미실행 | 작성 대기 |
| 브라우저 후속 목록 | 미실행 | 사용자 추후 확인 |

## 내 설명 3개

1. 검색·즐겨찾기의 데이터 흐름, state와 파생 값: 작성 대기
2. 선택·숨김·닫기 포커스, state/ref/Effect의 역할: 작성 대기
3. 메뉴·타이머의 수명과 정리 누락 재현: 작성 대기

## 독립 변경

- 즐겨찾기 해제 시 상세 닫기 정책의 구체적인 범위: 작성 대기
- 원래 버튼이 사라졌을 때 포커스 목적지: 작성 대기
- 변경 전 실패 / 변경 후 성공과 회귀 증거: 작성 대기
- AI 완성 코드 없이 해결한 방법: 작성 대기

## 도움과 다음 행동

- 읽은 공식 문서·해설: 작성 대기
- AI에 물어본 범위·받은 코드·완성본 열람 여부: 작성 대기
- 아직 설명하지 못하는 점: 작성 대기
- 다음 행동 하나: 작성 대기

교재 제작자의 검증 기록은 학습자의 실행 증거로 복사하지 않습니다. 설명·변경 과제 전에는 학습 완료로 표시하지 않습니다.
