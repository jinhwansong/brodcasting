- 학습 상태: 미시작
- 날짜·OS·Node·커밋·브라우저: 작성 대기
- 예상과 접근5~10줄: 작성 대기
- 인증/권한 재확인·빠른 방 이동·StrictMode·ack 유실 예상: 작성 대기
- AI 도움 전 첫 구현과 막힌 지점: 작성 대기

- 독립 ‘연결 한 개로 방 이동’의 요구·예상 실패: 작성 대기

- 설명3개와 독립 변경 확인: 대기
