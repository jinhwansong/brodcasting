# 5단계 브라우저 후속 확인

상태: **전체 미실행**. Node socket.io-client·HTTP·jsdom은 실제 브라우저 증거를 대신하지 않습니다. 사용자가 추후 진행합니다.

- 실행일·OS·브라우저2종/창·화면 크기·커밋: 작성 대기
- 로컬 전용 DB·계정·방 회원권 준비: 미실행

| 조작 | 확인할 결과 | 실행 결과 |
| --- | --- | --- |
| 두 브라우저/독립 계정 R1 | 양방향 일반 텍스트 송수신·현재 사용자 | 미실행 |
| 한쪽 R2로 이동 | R1/R2 메시지 분리·기존 구독 정리 | 미실행 |
| 비로그인·다른 origin·위조 입력 | 연결/이벤트 거부, 성공 표시 없음 | 미실행 |
| 연결 후 로그아웃·절대 만료 | 새 발송·새 수신 차단, 유휴 연결 종료 | 미실행 |
| operator 회원권 삭제 | 새 발송·수신 거부, 공지 관리자와 구분 | 미실행 |
| 빈 글·500/501 Unicode·HTML 문자열 | 경계 거부·일반 텍스트 표시 | 미실행 |
| 네트워크 중단·ack 유실 | 결과 불명 안내·초안 보존·자동 재전송 없음 | 미실행 |
| 같은 계정/다른 계정 재로그인 | 초안 보존/삭제·옛 목록/늦은 ack 무시 | 미실행 |
| StrictMode·빠른 방 이동·unmount | 연결·handler 누적 없음 | 미실행 |
| Tab/Enter·스크롤 목록·320px | 라벨·포커스·목록 스크롤·입력 접근 | 미실행 |
| 100개 초과·수동 재접속 | 보관 상한·연결 상태, 놓친 메시지 복구 주장 없음 | 미실행 |

Network/스크린샷/HAR에는 쿠키·CSRF·비밀번호·실제 사용자 데이터를 남기지 않습니다. 메서드·event 이름·상태·정제한 실패 종류로 기록합니다. 공개 서비스나 외부 부하를 대상으로 실행하지 않습니다.
