# 4단계 브라우저 후속 확인

상태: **전체 미실행**. 제작자의 jsdom·Node HTTP 검증은 실제 브라우저 증거를 대신하지 않습니다. 사용자가 추후 실행합니다.

- 실행 날짜·OS·브라우저·화면 크기·커밋: 작성 대기
- loopback API/화면 origin과 로컬 DB 준비: 미실행

| 조작 | 확인할 결과 | 실행 결과·증거 |
| --- | --- | --- |
| Tab/Enter로 가입·로그인·로그아웃 | 라벨·포커스·비밀번호 비움·결과 안내 | 미실행 |
| 320px와 데스크톱에서 계정·목록·공지 | 입력·버튼·긴 일반 텍스트 접근, 가로 넘침 없음 | 미실행 |
| 쿠키 속성 확인 | HttpOnly/Lax/path=/, 로컬 Secure=false 구분 | 미실행 |
| storage·Network 확인 | 인증값 localStorage 없음, unsafe CSRF 헤더, 원문 기록 금지 | 미실행 |
| 다른 origin·토큰 누락/위조 | 서버 거부와 DB 불변, 브라우저 차단과 구분 | 미실행 |
| 만료 중 공지 작성→같은 계정 로그인 | 초안 보존, 자동 재전송 없음 | 미실행 |
| 다른 계정 로그인·로그아웃 성공 | 이전 초안·권한·개인 상태 제거 | 미실행 |
| 권한 변경·403·응답 유실 | 초안 보존·재조회 안내, 거짓 성공 없음 | 미실행 |
| 느린 이전 계정·방 요청 | 현재 계정/방과 새 저장 중 상태 유지 | 미실행 |
| API 중지·재시작·로그아웃 후 재시작 | 세션/즐겨찾기 유지, 폐기 쿠키 거부 | 미실행 |
| 공지에 HTML 모양 문자열 입력 | 텍스트 표시, 요소/스크립트 생성 없음 | 미실행 |

스크린샷·HAR에는 자격증명·CSRF·쿠키·실제 사용자 데이터를 남기지 않습니다. 소켓 폐기는 5단계 이후 별도 확인입니다. 오류·미확인 결과도 그대로 기록하세요.
