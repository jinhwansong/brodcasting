# F1 — 글자는 글자로, 링크는 허용한 곳으로

채팅에 누군가 HTML처럼 생긴 글을 쓸 수 있어요. 내용을 보여 주는 일과 그 내용을 프로그램으로 실행하는 일은 다릅니다.

## 먼저 예상하기

실행 전에 무엇이 성공하고 무엇이 거부돼야 하는지 적으세요. src/notice-link.ts의 getApprovedNoticeLink 함수를 직접 구현합니다. 참고 완성본은 첫 구현 뒤에 비교하세요.

## 실습 순서

1. npm ci와 npm run check를 실행해 정상 주소 검사 실패를 확인합니다.
2. 앞뒤 공백을 제거한 뒤1~2048자 문자열만 받습니다. URL 파서로 절대 주소인지 확인합니다.
3. HTTPS인지, origin이 정확히 https://docs.example.test인지, 사용자명과 비밀번호가 없는지 검사합니다. 승인된 경우 정상화한 href, 나머지는 null을 돌려줍니다.
4. npm run dev로 http://127.0.0.1:5196을 엽니다. 제목의 <strong data-probe="title">안내</strong>가 글자로 보여야 합니다.
5. 공지 주소를 정상 주소·비슷한 다른 호스트·다른 포트·자격증명 포함 주소로 바꿉니다. 거부한 주소는 실제 링크가 되면 안 됩니다. 예시 도메인은 방문할 필요가 없습니다.

## 설명3개

1. React 글자 출력과 href 검사가 서로 다른 이유는 무엇인가요?
2. 호스트 이름이 포함됐는지만 검사하면 왜 부족한가요?
3. DOM 검사로 확인한 것과 실제 브라우저에서 확인한 것을 나눠 설명하세요.
