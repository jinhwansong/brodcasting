# 브라우저 측정 기록 — 미실행

제작 중 실제 브라우저 검증은 사용자 요청으로 보류했습니다. 아래를 직접 실행하기 전 수치를 채우지 않습니다.

| 실행 | 기기/브라우저/빌드 SHA | 속도·시간·표시 모드 | 입력 지연·긴 작업 | 메시지 DOM 수 | 시작/종료/중지 후 메모리 | 기록 경로 |
| --- | --- | --- | --- | --- | --- | --- |
| 개선 전 1~3 | | | | | | |
| 개선 후 1~3 | | | | | | |

1. 같은 브라우저의 빌드 미리보기를 사용합니다. 다른 탭·확장·전원 모드도 기록합니다.
2. 10→100→500개/초 순으로 올립니다. 기기가 힘들면 멈추고 그 속도를 기록합니다.
3. Performance 녹화를 켜고 입력·위쪽 읽기·새 글 버튼을 같은 순서로 실행합니다. Memory 수치가 GC 전후에 달라질 수 있음을 기록합니다.
4. 가로 360px·키보드 Tab/화살표/PageUp/PageDown으로 조작합니다. 긴 글 생략 표시의 한계도 기록합니다.
5. 방을 20번 바꾸고 중지/재시작합니다. 중지 뒤 CPU·타이머·메모리가 내려오는지 봅니다. 60초 실험을 반복해 장시간 추이도 확인합니다.
6. 가장 큰 병목 하나를 고르고 같은 조건으로 개선 전후를 다시 비교합니다. 결과를 실제 서버 수용 인원으로 바꾸어 말하지 않습니다.
