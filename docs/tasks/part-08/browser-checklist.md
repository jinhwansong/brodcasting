# 실제 재생 기록 — 미실행

제작 중 실제 브라우저 검증은 보류했습니다. 자동 검사의 모의 이벤트는 아래 완료를 대신하지 않습니다.

| 브라우저/OS/빌드 SHA | 재생/정지/탐색/음량 | 자막 | 재생 거절 안내 | 없는 파일·재시도 | 전환·채팅 동시 실행 | 실제 이벤트·증거 경로 |
| --- | --- | --- | --- | --- | --- | --- |
| 직접 기록 | | | | | | |

1. 두 영상의 실제 재생과 한국어 자막을 확인합니다. 무음 영상이라 소리 출력의 성공은 확인할 수 없고 음량 조작의 UI만 확인합니다.
2. Tab으로 기본 조작·선택·재시도에 접근합니다. 좁은 화면에서도 가로 넘침이 없는지 봅니다.
3. 없는 파일 선택으로 실제 error를 확인하고 정상 영상으로 전환해 복구합니다. 개발 서버가 없는 경로에 HTML을 반환할 수도 있으므로 실제 Network 응답도 기록합니다.
4. 네트워크 속도를 낮추고 캐시를 끈 뒤 waiting이 실제로 발생하는지 기록합니다. 4초 파일이라 발생하지 않으면 ‘재현 못 함’으로 남깁니다.
5. 자동재생 제한은 브라우저·설정별로 다릅니다. 직접 play 거절을 재현한 경우에만 기록합니다.
6. 채팅 10/100/500개/초와 함께 재생하고 입력·스크롤·전환을 확인합니다. 이 결과를 실제 라이브 지연이라고 부르지 않습니다.
