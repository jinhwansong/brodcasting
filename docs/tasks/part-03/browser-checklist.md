# 3단계 브라우저 후속 목록

**전부 미실행.** 사용자가 브라우저 검증을 나중에 진행하기로 했습니다. jsdom·Node HTTP·Vite 프록시 확인은 실제 브라우저 결과가 아닙니다.

- [ ] 390px/1280px에서 검색·정렬·즐겨찾기·페이지 버튼이 잘리지 않는지 확인
- [ ] Tab/Shift+Tab·Enter/Space로 모든 동작과 포커스 표시 확인
- [ ] 다음/이전·검색/정렬/즐겨찾기 조건 변경 시 offset 초기화 관찰
- [ ] 저장 대기·성공·실패·재조회 안내와 보조기술 읽기 확인
- [ ] 새로고침·새 탭에서 서버 저장 상태 확인
- [ ] 빠른 조건 변경과 느린 이전 응답이 최신 화면을 덮지 않는지 확인
- [ ] Network의 인코딩·limit/offset·상태 코드·no-store 확인
- [ ] 없는 id·DB 중단503·재시도 화면 확인
- [ ] 콘솔 오류·중복 이벤트·언마운트 뒤 자원 확인

실제 날짜·브라우저·뷰포트·재현 조건과 정제한 증거를 제출 기록에 추가하세요. 원시 연결 정보/비밀번호를 캡처하지 않습니다.
