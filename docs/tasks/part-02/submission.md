# 2단계 제출 기록

- 학습 상태: 미시작
- 작성자·날짜·브랜치·커밋·Node·OS: 작성 대기
- 브라우저 버전·뷰포트: 추후 확인

## 실행 전 예상과 첫 구현

1. r/re 응답 역전: 작성 대기
2. 타입 선언과 숫자/null/배열 입력: 작성 대기
3. 클라이언트 abort와 서버 작업: 작성 대기

- AI 도움 전 직접 시도한 A/B/C/D: 작성 대기
- 바꾼 파일과 이유·틀린 예상: 작성 대기

## 느린 구간과 오류 하나 분석

- 요청 메서드·경로·검색/정렬 조건: 작성 대기
- 요청 순서·응답 순서·상태 코드: 작성 대기
- 기다린 구간·본문 수신·파싱·화면 반영을 구분한 근거: 작성 대기
- 선택한 오류의 요청→응답/연결 실패→원인→복구: 작성 대기
- 브라우저 Network 기록 또는 자동 HTTP 결과의 출처: 작성 대기

## 내 설명 3개

1. App부터 Module/DI·Controller·DTO·Service와 화면까지: 작성 대기
2. 최신성·취소·서버 작업 중단의 차이: 작성 대기
3. 오류·파서/필드 검증·캐시 정책의 위치: 작성 대기

## 독립 변경과 도움 범위

- timeout 요구사항·표시·재시도 정책: 작성 대기
- 직접 추가한 경계·정리·회귀 검증과 수정 전후 결과: 작성 대기
- AI가 준 코드·힌트·참고 완성본 열람 여부: 작성 대기
- 아직 모르는 점·다음 행동 하나: 작성 대기

토큰·쿠키·실제 개인정보가 들어 있는 HAR/로그를 커밋하지 않습니다. 제작자의 실행 결과를 자신의 증거로 복사하지 않습니다. 설명·독립 변경 전에는 학습 완료로 기록하지 않습니다.
