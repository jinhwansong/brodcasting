# 2단계 브라우저 후속 검증

**전부 미실행.** 사용자가 실제 브라우저 확인을 나중에 진행하기로 했습니다. 제작 중 브라우저를 설치하거나 렌더링을 검증하지 않습니다. Node HTTP·jsdom 검증을 Network 패널이나 실제 브라우저 결과로 기록하지 않습니다.

학습자의 A~D 구현 뒤 두 터미널에서 API와 client를 실행하세요. 결과에는 커밋·OS·Node·브라우저·뷰포트·날짜를 남깁니다.

- [ ] 목록 API 200, 상세 200, 빈 목록, 없는 상세 404가 화면과 일치
- [ ] 검색 r 다음 re에서 요청/응답 순서와 최종 화면 기록
- [ ] 진행 중 요청 취소 표시와 서버 작업 취소 보장을 구분
- [ ] 503·API 터미널 중지·재시작 후 같은 조건 재시도
- [ ] 목록 실패와 상세 실패가 서로의 선택·조건을 지우지 않음
- [ ] 상세 조회 중 닫기·다른 id 선택에서 오래된 제목/오류가 다시 나타나지 않음
- [ ] 서버가 거부한 잘못된 입력의 상태 코드·응답, UI 입력 제한과 구분
- [ ] Cache-Control: no-store·반복 요청과 실제 transfer/cache 표시 확인
- [ ] 390px/1280px·긴 검색어·HTTP 실험 입력에서 가로 넘침 없음
- [ ] Tab/Shift+Tab·상세 제목 포커스·닫기 복귀·옵션 Escape/바깥 클릭
- [ ] 스크린리더의 로딩·오류·영역·라벨·즐겨찾기 상태 전달

체크와 화면 증거는 실제 실행 후에만 추가합니다. 원시 Network 내보내기에는 민감 정보가 포함될 수 있으므로 정제한 메서드·경로·상태·시간·오류 종류를 우선 제출합니다.
