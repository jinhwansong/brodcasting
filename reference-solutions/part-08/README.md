# 8단계 참고 완성본

제작자 비교용입니다. 학습자의 첫 예상·구현 전에는 읽거나 복사하지 않습니다. 본 과제의 독립 변경 답은 포함하지 않습니다.

이 폴더만 새 위치에 복사해 npm ci, npm run typecheck, npm run build, npm run dev로 실행할 수 있습니다. Node 범위는 package.json을 따릅니다. 브라우저 주소는 5188 포트입니다. npm run preview는 빌드 뒤 실행합니다.

학습 안내·공개 검사는 원본 저장소의 docs/tasks/part-08/와 checks/part-08/에 있습니다. 자체 제작한 영상·자막의 사용 허가는 public/media/LICENSE.md에 있습니다.
