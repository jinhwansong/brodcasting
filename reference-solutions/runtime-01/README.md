# 알림 과정 1주 참고 완성본

첫 시도 후 [교재](../../docs/tasks/runtime-01/README.md)와 비교하는 독립 완성본입니다. 소스 폴더만 다른 위치로 복사해 실행할 수 있습니다. Node engines 범위를 따르며 외부 의존성은 없습니다.

```sh
npm ci
npm run check
npm run experiment -- 1000000
```

실제 CPU 계산 다섯 방식·세 번 반복, 객체 복사/명시적 공유, 자식 종료를 JSON으로 출력합니다. 외부 서버나 GPU를 사용하지 않습니다. 시작 비용이 포함된 고정 순서 실험이며 운영 수용 능력이나 멀티코어 확장 비율을 측정하지 않습니다. 원래 공개 검사는 15개입니다. [검증 기록](../../docs/verification/runtime-01.md)은 학습자의 성과가 아닙니다.
