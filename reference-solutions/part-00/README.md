# 0단계 참고 완성본

스포일러가 있습니다. 학습 보조의 기본 읽기·실행 대상이 아닙니다. 먼저 학습자의 예상과 첫 구현을 작성하세요. 이 코드가 통과해도 학습자가 통과한 것은 아닙니다.

## 독립 실행

Node.js 24.x의 24.15.0 이상과 npm을 권장합니다(검증: 24.19.0). 전체 지원 범위는 package.json의 engines에 있습니다. 이 폴더의 파일만 복사해도 실행 환경을 설치할 수 있습니다. 서버·API 키·실제 개인정보가 필요하지 않습니다.

```sh
cd reference-solutions/part-00
npm ci
npm run typecheck
npm run build
npm run dev
```

터미널에 나오는 로컬 주소를 여세요. 즐겨찾기는 메모리에만 있으며 새로고침하면 초기화됩니다.

## 동일 행동 검증 (교재 제작자용)

저장소 전체를 받은 뒤 루트에서 `npm ci`, `npm run check:reference`를 실행합니다. 공개된 `checks/part-00/`를 그대로 사용하며 완성본 내부를 검사해 정답을 추측하는 테스트는 사용하지 않습니다.

브라우저 검증은 루트에서 `npx playwright install chromium`, 이 폴더의 `npm run build`, 루트의 `npm run test:e2e:reference` 순서입니다. 실제 실행 여부는 [제작 검증 기록](../../docs/verification/part-00.md)에 있습니다. 실행 도구 설치가 실패했다면 통과로 간주하지 마세요.

## 설계와 한계

- 조회는 원본에서 필터링한 새 배열을 정렬합니다. 동률은 id로 결정합니다.
- 즐겨찾기는 id만 저장하며 새 Set을 만듭니다.
- UI 표시는 검색 조건에서 파생되고 별도 조회 결과 상태로 중복 저장하지 않습니다.
- 모의 로더는 160ms 뒤 정상·빈 데이터·오류를 만듭니다. 실제 네트워크 성능 수치가 아닙니다.
- Effect 정리에서 늦은 결과를 무시합니다. 실제 서버 작업을 중단하는 구현은 아닙니다.
- 재시도는 정상 모드로 새 요청을 만듭니다.
- 영상, 인증, 서버, 영속 저장, 대규모 성능·운영 경험은 이번 완성본 범위가 아닙니다.
