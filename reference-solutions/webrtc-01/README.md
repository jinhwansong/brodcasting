# WebRTC 실습 참고 완성본

[과제 안내](../../docs/tasks/webrtc-01/README.md)를 먼저 읽습니다. 제공된 사이트·로그인·DB·자원 정리 코드는 선수 코드입니다. 학습 상태는0·미시작을 유지합니다.

이 폴더에서 npm ci, npm run typecheck, npm run check를 실행합니다. 실제 API 준비는 [사이트 실행 안내](../../apps/broadcast/README.md), LAN HTTPS는 [쉬운 실습 설명](../../docs/tasks/webrtc-01/lesson.md)을 따릅니다. 이 복사본의 .env와 dev:api/dev 명령을 사용하고 다른 복사본과 동시에 같은 포트를 열지 않습니다.

정답을 학습 폴더에 자동으로 복사하지 않습니다.
